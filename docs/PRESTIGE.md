# NJSIAA prestige points

## Official source

NJSIAA 2025-2026 Boys Wrestling Individual Championships regulations — District Pre-Seed Chart (Prestige Points / Own Merit column):

https://www.njsiaa.org/sites/default/files/documents/2025-11/wrestling-boys-individual-regs-2025-26.pdf

Machine copy: `data/njsiaa_prestige.json`. Code: `prestige.py`.

Do **not** put the source URL or Trackwrestling season/team IDs on public pages; keep citations in code/docs only.

## Site rule

Jeff (2026-11-01): prestige is based on the wrestler's **highest CAREER placement** across all prior seasons on record — **not** only the immediately prior year. Current-season placements are excluded from the calculation (prestige is what a wrestler carries *into* the season).

## Chart (prestige points)

| Advancement | Prestige |
|-------------|----------|
| State Champ | 125 |
| 2nd–8th in States | 115 … 85 |
| WB4–WB1 in States | 80 … 65 |
| 5th / 6th in Regions | 50 / 45 |
| WB1 / 2v3 in Regions | 40 / 35 |
| 4th / Quarters / Prelim in Districts | 15 / 10 / 5 |

When awards list district 1st–3rd or region 1st–4th without a deeper row, we apply the documented **inferred floors** (region qualifier → 65; district qualifier → 40). Exact state placements always win when present.
